# App Tô Màu — Kế hoạch xây dựng

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA tô màu chạy trên iPhone/Android/máy tính: tô vùng một chạm, cọ tự do, bảng màu chi tiết, thư viện hình 3 cấp, import ảnh thành tranh tô.

**Architecture:** Mỗi bức tranh = lớp nét (SVG hoặc PNG) đè lên lớp màu (canvas). Khi mở hình, nét được raster hoá và gán nhãn vùng một lần (bản đồ vùng); chạm tô = tra nhãn và tô mask. Xử lý nặng chạy trong Web Worker; dữ liệu lưu trong IndexedDB.

**Tech Stack:** Vite 5, TypeScript 5 (strict), vanilla DOM, Canvas 2D, Web Worker, `idb`, `vite-plugin-pwa`, `esm-potrace-wasm`, Vitest (+ `fake-indexeddb`), Playwright, GitHub Actions → GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-27-app-to-mau-design.md`

## Global Constraints

- Giao diện 100% tiếng Việt.
- Không gọi mạng ngoài sau khi tải app; ảnh import không rời khỏi máy. Không AI, không máy chủ.
- Độ phân giải làm việc: cạnh dài tối đa **2048 px**; **1536 px** nếu iOS hoặc `navigator.deviceMemory <= 4`.
- Hoàn tác tối thiểu **30** bước.
- Tự lưu debounce **1000 ms**.
- Màu gần đây: **8** ô. Hàng màu nhanh: **24** màu.
- Thư viện có sẵn: **15–20** hình SVG, cấp Dễ (5–15 vùng), Vừa (20–60), Khó (100+).
- Một ngón = tô/vẽ; hai ngón = phóng to/kéo. Máy tính: lăn chuột = zoom, kéo chuột giữa hoặc Space+kéo = pan.
- "Giữ trong vùng" cho cọ: có, mặc định **tắt**.
- Vite `base: '/to-mau/'` (GitHub Pages của repo `hiull/to-mau`).
- Kiểu ảnh dùng chung trong lõi: `type Gray = { width: number; height: number; data: Uint8Array }` (0 = đen/nét, 255 = trắng), `type RGBA = { width: number; height: number; data: Uint8ClampedArray }`. Lõi không phụ thuộc DOM để test được trong Node.

## Review Focus

1. **Chạm đúng lên nét** → tô vùng gần nhất (không bỏ qua, không tô nét). Test ở Task 2 (`nearestRegion`).
2. **Chạm tô lại cùng màu** → không tạo bước hoàn tác thừa. Test ở Task 3.
3. **Bắt đầu một ngón rồi đặt ngón thứ hai** (bắt đầu pinch) → nét cọ/lần tô dở bị huỷ, không để lại vết. Test e2e ở Task 6.
4. **Ảnh import PNG nền trong suốt hoặc ảnh 12+ MP** → nền trong suốt coi là trắng; ảnh lớn thu về độ phân giải làm việc, không crash. Test ở Task 9.
5. **IndexedDB không dùng được** (tab ẩn danh, bị chặn) → app vẫn tô được, hiện cảnh báo "Không lưu được tranh trên trình duyệt này". Test ở Task 5.

### Task 9: Import ảnh thành tranh nét

  export function guessMode(img: RGBA): ImportMode;               // tỉ lệ pixel gần trắng/gần đen > 0.85 → 'drawing'

Ảnh vào được thu về `workingSize` trước khi xử lý (giải mã bằng `createImageBitmap` với `resizeWidth/resizeHeight` để không giữ ảnh gốc 12MP trong canvas).
